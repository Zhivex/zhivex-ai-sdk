# Agents/Gateway implementation evidence

Baseline runtime: `631b73363607d0831f6f7e0d39e52cf32d4892ef`. Four full offline matrices (two Node v24.11.0, two Bun v1.4.0), each with 126 scenarios, one warmup and two measured repetitions: 1,008 measured trials and 7,056 correct task instances. The Node runs started from clean source. The Bun runs record dirty source because later HU source edits were underway; the built agent/gateway artifacts and runner remained unchanged and their hashes were checked across every run. These are local results, not live or CI certification.

Files `agw-{node,bun}-{1,2}.json` contain raw trials; matching Markdown files show p50/p95 and throughput. `agw-{node,bun}-bands.json` derives exploratory investigation bands from the paired runs. Two measured repetitions are insufficient for a production latency gate. The benchmark guide explains measurement boundaries, limits and reproduction.

`group-concurrency.json` compares 16 members, 10 steps and 64-byte payloads with default concurrency versus maxConcurrency=3. Both are correct. Observed p50/p95: 49.94/51.58 ms default and 48.24/48.99 ms bounded. This fixture measures local orchestration and does not imply faster live execution with fewer workers.

`checkpoint-before.json` and `checkpoint-after.json` instrument full-state JSON serialization with the same 1/10/100-step workload and 1,024-byte results. They record the built agent hashes and raw CPU/RSS/timing/byte data. Full-state serialization counts fell 25→22, 151→130, and 1,411→1,210 respectively, while writes remained 3/21/201. The reduction is one serialization per persistence boundary. Checkpoint count, logical contents, CAS revision advancement and isolation remain unchanged, except the size check now includes normalization and the next revision. Instrumented timing is not an uninstrumented performance claim.

`routing-tool-overhead.json` records five measured repetitions after warmup for legacy routing, metrics, circuit breaking, adaptive routing and serial/independent tools. All 2,010 measured task instances passed. Gateway batch p95 was 1.72/1.42/1.24/3.41 ms respectively for 100 mocked tasks; sequential batches include JIT and host noise, so these values are exploratory and do not establish an overhead percentage. Two synthetic 5 ms tools measured p50 12.02 ms serial and 6.11 ms independent. Reproduce with `node scripts/benchmarks/routing-tool-overhead.mjs <output.json>` after building. These observations demonstrate fixture overlap, not live-provider or competitive performance.
