# Zhivex AI SDK Roadmap

This roadmap communicates direction rather than a fixed delivery commitment.
Provider APIs, model availability, and release sequencing can change.

## Current priorities

### Stable cross-provider contract

- keep portable text, streaming, structured output, and tool semantics aligned
- publish explicit capability metadata and fail fast on unsupported options
- maintain TypeScript and Python parity for stable foundation APIs

### Durable agent operations

- strengthen recovery, idempotency, approvals, replay, and cancellation
- expand production examples for Postgres, workers, and API runtimes
- keep tracing, evaluation, cost, and safety artifacts bounded and redacted

### Developer experience

- maintain concise entry-point documentation and task-oriented guides
- improve starter applications for Bun, Next.js, React, and server runtimes
- publish migration guidance and release notes for every stable release

### Provider quality

- certify Tier-1 providers with contract tests and credentialed release smokes
- track upstream deprecations without silently changing portable behavior
- preserve native escape hatches for hosted tools, realtime, media, and files
